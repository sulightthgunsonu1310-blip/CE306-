# DAILY CATER - ระบบรับออเดอร์เบรคและอาหารกลางวัน (CE306)

เว็บแอปพลิเคชันสำหรับสั่งชุดเบรค (Snackbox) และอาหารกลางวัน (Lunchbox) พร้อมระบบบริหารจัดการออเดอร์ร้านค้าและเงื่อนไขการชำระเงินมัดจำ 50%

## คุณสมบัติหลักของระบบ
- **ฝั่งลูกค้า (Customer Storefront):** เลือกดูและค้นหาเมนูอาหาร 12 รายการ สั่งซื้อพร้อมบันทึกข้อมูลลูกค้าลงฐานข้อมูลอัตโนมัติ และชำระมัดจำ 50% ผ่านพร้อมเพย์หรือเงินสด
- **ระบบติดตามสถานะ (Order History):** แสดงประวัติการสั่งซื้อและอัปเดตสถานะการจัดทำอาหารจากทางร้านแบบ Real-time
- **ระบบหลังร้าน (Admin Dashboard):** ป้องกันการเข้าถึงด้วยรหัสผ่าน (`67111873`) มีกราฟเปรียบเทียบรายได้รายเดือน จัดการสถานะออเดอร์ แสดง QR Code รับเงินปลายทาง และเพิ่มเมนูอาหารใหม่
